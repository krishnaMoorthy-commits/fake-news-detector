About project

Fake News Detection Using Data Science

An academic project that walks the full path from raw text to a trained classifier to a usable web interface — with an explicit statement of what it cannot do.

Introduction

Fake news refers to false or misleading information presented as legitimate news. The rapid spread of misinformation through social media and online platforms has made it increasingly difficult for readers to distinguish credible reporting from fabricated or misleading content.

This project explores how Data Science and Machine Learning techniques can be applied to automatically flag text that resembles patterns commonly found in misleading news articles.

Why detection matters

Automated analysis can help triage large volumes of text far faster than manual review, giving readers, moderators and researchers an additional signal to consider. While it cannot replace human judgement or professional fact-checking, it can act as a useful first-pass filter, especially at scale.

The role of Data Science

This project follows a standard Data Science workflow: collecting labelled data, cleaning and preparing the text, engineering numerical features from that text, training a Machine Learning model on those features, and evaluating how well the trained model generalizes to unseen examples.

Natural Language Processing

Before any modelling can happen, raw text must be converted into a form a computer can work with. This involves lowercasing, removing HTML, URLs and punctuation, and normalizing whitespace, followed by numerical representation via TF-IDF (Term Frequency – Inverse Document Frequency), which weighs words by how distinctive they are across the dataset.

Preprocessing actually executed
lowercase → strip HTML tags → strip URLs → strip punctuation and digits → collapse whitespace

Machine Learning

Once text is represented numerically, a supervised classification algorithm is trained on examples labelled REAL or FAKE. The trained model learns statistical patterns that correlate with each class and uses them to classify new, unseen text.

Algorithms: discussed vs. implemented

The algorithms below are discussed for academic completeness. Only Logistic Regression with TF-IDF features is wired into this web application.

Logistic Regression Implemented

A linear model that estimates the probability of a class using a sigmoid function. Simple, fast and interpretable — well suited to sparse TF-IDF text features.

Naive Bayes Discussed

A probabilistic classifier based on Bayes' theorem, assuming feature independence. Popular for text classification due to its speed and simplicity.

Decision Tree Discussed

A tree-structured model that splits data based on feature values. Easy to interpret but prone to overfitting on high-dimensional text data.

Random Forest Discussed

An ensemble of decision trees that averages predictions to reduce overfitting and improve generalization.

Support Vector Machine Discussed

Finds an optimal separating hyperplane between classes; effective in high-dimensional spaces such as TF-IDF vectors.

Applications

Domains where text-based screening is commonly discussed:

Social media posts Health news Political news Sports news Celebrity news Disaster news Financial news Education news

Advantages

  • Fast, automated classification of large volumes of text
  • Scalable text processing pipeline
  • Consistent, data-driven decision criteria
  • Can be retrained as new labelled data becomes available
  • Runs entirely in one Flask application with no external service dependency

Challenges and limitations

  • Fake news tactics and topics constantly evolve
  • Sarcasm and satire can be difficult for models to detect
  • Machine Learning models can and do produce incorrect predictions
  • Reliable, well-labelled training data is required
  • Dataset bias can affect prediction quality
  • Text-based classification does not independently verify facts against the real world
  • Session statistics are per-visitor and are not stored in a database

Conclusion

This project demonstrates, at an academic level, how Data Science and Machine Learning techniques can be combined to build a functional text classification system for fake-news detection. Its value is educational and exploratory: it shows the end-to-end pipeline from raw text to a trained model to a usable web interface.

It is not a certified fact-checking tool, and its predictions should always be treated as a statistical signal rather than a verified conclusion.
