What happens to your text

  • Cleaning — lowercased; HTML tags, URLs and punctuation removed; whitespace collapsed.
  • Vectorization — the TF-IDF vectorizer fitted at training time converts the cleaned text into numeric features.
  • Classification — Logistic Regression returns a label and, where available, the probability of that class.
  • Handling — the text is processed by this Flask server. It is not sent to an external fact-checking service.

Reading the output

How to interpret the result page

Label

The classifier assigns exactly one class, REAL or FAKE. The label is accompanied by an icon and a written word so it never depends on colour alone.

Confidence

If the model exposes class probabilities, the predicted class probability is shown as a percentage. When it cannot be computed the value is simply omitted.

Context

The page echoes your submitted text, explains the outcome in plain language and repeats the limitation: consult reliable reporting before drawing conclusions.
