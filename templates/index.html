{# ------------------------------------------------------------------ #} {# TECHNOLOGY #} {# ------------------------------------------------------------------ #}

Core technology

Machine learning, applied to language

Everything described here reflects what the running application actually does — no simulated AI and no invented capabilities.

Machine Learning

A Logistic Regression classifier trained with scikit-learn learns the statistical patterns that separate the REAL and FAKE labels present in the training dataset.

Natural Language Processing

Raw text is lowercased, stripped of HTML tags, URLs and punctuation, then collapsed to clean whitespace before it ever reaches the model.

Text Classification

TF-IDF turns the cleaned text into numeric features, weighing each term by how distinctive it is across the documents seen during training.

Model-based Prediction

The saved vectorizer and classifier bundle is loaded once per process and reused to label new, unseen text submitted through the form.

{# ------------------------------------------------------------------ #} {# HOW IT WORKS #} {# ------------------------------------------------------------------ #}

How it works

Three steps from raw text to prediction

The full path your submission travels, from the browser to the trained model and back.

Enter a headline or article

Paste a news headline, a full article body, or both into the analysis form. Server-side validation confirms the text is present and within the 10,000-character limit before anything is processed.

Submit it to the pipeline

The Flask backend cleans the text with the same preprocessing used during training, vectorizes it with the fitted TF-IDF vectorizer, and passes the features to the trained classifier.

Review the result

You receive a REAL or FAKE label, a confidence percentage when the model exposes class probabilities, and a plain-language note on what that output does and does not mean.

{# ------------------------------------------------------------------ #} {# FEATURES #} {# ------------------------------------------------------------------ #}

Capabilities

What this project really does

Each item below is implemented in the source code. Anything not listed here is not part of the application.

Machine-learning text classification

A trained scikit-learn classifier labels submitted text as REAL or FAKE using TF-IDF features built from your headline and article.

Prediction result page

The verdict is shown with a plain-language explanation, the text you submitted, and a reminder that the output is a model prediction.

Confidence score

When the classifier exposes class probabilities, the predicted class probability is displayed as a percentage. If it cannot be computed, the score is omitted rather than invented.

Session prediction history

Running totals for your current browser session — checked, real and fake — stored in the Flask session cookie and shown in the snapshot below.

Server-side validation

Empty submissions and over-length input are rejected by Flask before the model runs, so the checks cannot be bypassed by disabling JavaScript.

Graceful model handling

If the trained model file is missing or unreadable, the interface explains how to train one instead of failing with a stack trace.

Not included in this build: fact-checking against independent sources, per-word explainability or feature attribution, author/date metadata analysis, and permanent storage of submitted text. These are deliberately not advertised as working features.
